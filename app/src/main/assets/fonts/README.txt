Vazirmatn and Inter (weights 400/500/600/700) are placed here by tools/fetch_fonts.sh
(the GitHub Actions workflow runs it before every build). Both fonts are under the SIL Open Font License 1.1;
the OFL texts are copied next to the fonts. If the .ttf files are missing, NEXUS falls back to the system font
and Settings > About shows which fonts are bundled.
